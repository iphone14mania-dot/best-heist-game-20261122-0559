Nightvault — The Gilded Heist: a top-down 2D stealth heist game. Three heists (a museum, a bank vault, a sky casino), guards with sweeping vision cones, security cameras, a rising alarm meter, tools bought with loot credits (noisemaker coins, smoke pellets, EMP charges, lockpicks), and a getaway van that only opens once the target is secured. Keyboard + mouse, no libraries, no network — all art and sound are drawn and synthesized in code.

## Run it

```sh
python3 -m http.server --directory game
```

Then open http://localhost:8000 in a desktop browser. `?shot=cover|loadout|chase|getaway` stages a fixed scene for screenshots.
